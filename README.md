# Unikit

Unikit is a set of seven free, open-source tools for university students who use Moodle. Each runs in your browser with nothing to install and nothing uploaded.

Visit **[ashgar99.github.io](https://ashgar99.github.io/)** to see all seven tools.

| Tool | What it does |
| --- | --- |
| [Modzip](https://ashgar99.github.io/moodle-module-downloader/) | Save every file from a Moodle module as one zip, organised by section. |
| [Subzip](https://ashgar99.github.io/subzip/) | Keep every assignment you handed in, with your grades and feedback. |
| [Duecal](https://ashgar99.github.io/duecal/) | Put every Moodle deadline in your calendar, with reminders. |
| [Termcal](https://ashgar99.github.io/termcal/) | Enter your timetable once and have the whole term in your calendar. |
| [Gradewise](https://ashgar99.github.io/gradewise/) | See your degree classification so far, and what you need for a First. |
| [Wordfair](https://ashgar99.github.io/wordfair/) | Count your essay the way markers do, without references or footnotes. |
| [Readable](https://ashgar99.github.io/readable/) | Make scanned readings searchable, including Japanese, Chinese and Korean. |

This repository hosts the Unikit home page, along with `robots.txt`, `sitemap.xml` and `llms.txt` for the whole site. Each tool has its own repository.

Unikit is not affiliated with or endorsed by Moodle or any university.
